## Objetivo do software
O UBIANI é um sistema desenvolvido para realizar o cadastro e o gerenciamento de animes, permitindo organizar informações como título, descrição, classificação indicativa, ano de lançamento e gênero.

O objetivo é oferecer uma interface simples e intuitiva para facilitar o armazenamento, a consulta e a administração dos animes cadastrados.

## Funcionalidades do sistema (requisitos)

- **Cadastrar animes:** permite adicionar novos animes ao sistema.
- **Consultar animes:** permite visualizar os animes cadastrados.
- **Pesquisar animes:** permite localizar animes pelo título.
- **Editar animes:** permite atualizar as informações dos registros existentes.
- **Excluir animes:** permite remover animes cadastrados.
- **Gerenciar gêneros:** utiliza os gêneros armazenados no banco de dados para classificar os animes.
- **Armazenar dados:** utiliza o banco de dados MySQL para manter as informações salvas.

## Banco de dados
O sistema utiliza o MySQL para armazenar os dados dos animes e seus respectivos gêneros.

A comunicação entre a aplicação Java e o banco de dados é realizada por meio do JDBC.
